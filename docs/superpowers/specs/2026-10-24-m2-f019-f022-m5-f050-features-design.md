# Topify Feature Design Specification: F022, F019 & F050

**Date:** 2026-10-24  
**Status:** Approved  
**Author:** Antigravity Engineering  
**Scope:** Implementation of missing M2 (F022, F019) and M5 (F050) modules ready for QA testing.

---

## 1. Executive Summary & Goals

This specification defines the architectural design, API contracts, UI components, and verification strategy for three features marked "Ready to Test" in Topify's release matrix:

1. **[F022] M2. Content Studio / Đăng bài viết: Đăng ngẫu nhiên giờ trong khung (Random Time Window)**
   - Allow users on `/create` to select "Đăng ngẫu nhiên trong khung (F022)" alongside "Đăng ngay" and "Lên lịch chính xác".
   - Provide 4 Golden-Hour presets (Sáng, Trưa, Chiều, Tối) and custom Start/End times.
   - For multi-video posts, dynamically space or randomize publishing moments across the window to defeat platform spam algorithms.
   - Live random time preview with a "🎲 Random lại" reshuffle button.

2. **[F019] M2. Content Studio / Quản lý bài viết: Import bài từ Google Drive & Excel (Bulk Post Import)**
   - Enable importing bulk posts from local files (`.xlsx`, `.xls`, `.csv`) and public Google Sheets / Google Drive links.
   - Dedicated Tab in `ContentStudio.tsx` + "Import từ Excel / Drive (F019)" header action in `Posts.tsx`.
   - Backend parsing engine with flexible column header mapping (`Tiêu đề/Title`, `Nội dung/Caption`, `Bình luận đầu/First Comment`, `Hashtags`, `Nền tảng/Platforms`, `Thời gian lên lịch/Scheduled At`, `Media URL`).
   - Interactive Preview Table Modal with inline cell editing, row removal, and validation status indicators (Valid / Warning / Error).
   - Downloadable standardized templates: `Mau_Import_Bai_Viet_Topify.xlsx` and CSV.
   - Batch creation of `Post` and `PostPlatform` records in Prisma DB as `DRAFT` or `SCHEDULED`.

3. **[F050] M5. Analytics: So sánh hiệu suất theo khoảng thời gian (Period Comparison: MoM / YoY)**
   - Add a "So sánh với kỳ trước (MoM / Prior Period)" toggle in `Analytics.tsx` alongside timeframe selectors (`7d`, `30d`, `90d`, `custom`).
   - Backend calculation in `lib/analytics/engine.ts` and `/api/analytics/period-comparison` computing current period metrics vs previous period metrics (Reach, Views, Engagements, Leads, Won Deals, ROI).
   - Calculate percentage growth: $\Delta\% = \frac{\text{Current} - \text{Prior}}{\text{Prior}} \times 100\%$, displayed as green badge (`🟩 +X%`) or red badge (`🟥 -X%`).
   - Dual-line visualization (Solid line = Current Period, Dashed line = Previous Period) for performance trajectory over time.

## 2. Feature Specification: F022 (Random Time Window)

### 2.1 UI / UX on `/create`
- **Publish Mode Selector:**
  - `publishMode: 'now' | 'schedule' | 'random_window'`
  - 3 clickable cards with icons: `Send` (Đăng ngay), `Calendar` (Lên lịch chính xác), `Shuffle` / `Dices` (Đăng ngẫu nhiên trong khung).
- **Time Window Configuration Card:**
  - Date input: `randomDate` (defaults to today or tomorrow).
  - Quick Golden-Hour Presets:
    - 🌅 **Khung Sáng:** `08:30 - 11:30` (Tương tác đầu ngày)
    - ☀️ **Khung Trưa:** `12:00 - 13:45` (Giờ nghỉ trưa)
    - 🌆 **Khung Chiều:** `16:00 - 18:00` (Giờ tan tầm)
    - 🌙 **Khung Tối (Hot):** `19:30 - 22:30` (Giờ vàng triệu view)
    - ⚙️ **Khung Tùy Chỉnh:** User inputs `startTime` and `endTime`.
  - Multi-video dispersion:
    - If `videos.length > 1`: provides toggle "Phân bổ đều thời gian giữa các video trong khung" (e.g. 3 videos in 09:00 - 11:30 -> video 1 at 09:25, video 2 at 10:15, video 3 at 11:05) vs "Ngẫu nhiên độc lập".
  - Live Preview Badge:
    - Displays: `🎲 Mốc giờ đăng ngẫu nhiên dự kiến: HH:mm (ngày dd/MM/yyyy)`
    - Button: `🎲 Random lại` allowing instant re-calculation.

### 2.2 Backend & Data Persistence
- Client sends:
  ```json
  {
    "scheduledAt": "2026-10-25T14:42:00.000Z",
    "isRandomWindow": true,
    "randomWindowStart": "2026-10-25T12:30:00.000Z",
    "randomWindowEnd": "2026-10-25T15:30:00.000Z"
  }
  ```
- Validation in `POST /api/posts`:
  - `scheduledAt` must be in the future.
  - If `randomWindowStart` & `randomWindowEnd` are provided, verify `scheduledAt` is strictly between start and end.
- Post status is saved as `SCHEDULED`. Existing background checker `lib/queue/scheduler.ts` picks it up when `scheduledAt <= now` and publishes smoothly.

## 3. Feature Specification: F019 (Bulk Post Import from Excel & Drive)

### 3.1 Data Schema & Template Columns
The engine supports flexible header names:
- **Tiêu đề** / `Title` (Required)
- **Nội dung** / `Caption` (Optional)
- **Bình luận đầu** / `First Comment` (Optional)
- **Hashtags** / `Thẻ` (Optional)
- **Nền tảng** / `Platforms` (Optional: comma-separated list of `TIKTOK`, `FACEBOOK`, `INSTAGRAM`, `YOUTUBE`, `ZALO`)
- **Thời gian lên lịch** / `Scheduled At` (Optional: `YYYY-MM-DD HH:mm`)
- **Đường dẫn Media** / `Media URL` (Optional)

### 3.2 Backend Endpoints
1. `POST /api/content-studio/import/parse`:
   - Handles file upload (`multipart/form-data`) or `{ sheetUrl: string }`.
   - For Google Sheets: extracts Sheet ID, fetches `https://docs.google.com/spreadsheets/d/{ID}/export?format=csv`, parses with `xlsx.read`.
   - Validates every row: marks `isValid`, returns error/warning strings.
   - Returns `{ success: true, total: N, valid: X, warnings: Y, errors: Z, rows: [...] }`.
2. `POST /api/content-studio/import/save`:
   - Accepts list of validated post items.
   - Creates `Post` and `PostPlatform` records in Prisma DB within a transaction.
   - Sets status to `SCHEDULED` if future time is present, otherwise `DRAFT`.
3. `GET /api/content-studio/import/template`:
   - Returns downloadable `Mau_Import_Bai_Viet_Topify.xlsx` with sample data and column documentation.

### 3.3 Frontend Components
- `ImportPostsModal.tsx`:
  - Step 1: Upload tab (Drag & Drop `.xlsx`, `.csv`) + Google Sheets tab (URL input + guide).
  - Step 2: Data Preview Table with metric counters, row checkboxes, inline editing, delete row button.
  - Step 3: Batch Confirm buttons: "Nhập bản thảo (Draft)" and "Lên lịch & Lưu bài".
- Integration in `ContentStudio.tsx`: Tab 4 `Import Excel / Google Drive (F019)`.
- Integration in `Posts.tsx`: Header button `Import từ Excel / Drive (F019)`.

## 4. Feature Specification: F050 (Period Comparison: MoM / YoY)

### 4.1 Backend Engine
- Location: `lib/analytics/engine.ts` & `app/api/analytics/period-comparison/route.ts`
- Calculation logic:
  - Current Period: $[T_1, T_2]$ based on timeframe (`7d`, `30d`, `90d` or custom).
  - Prior Period: $[T_1 - \text{duration}, T_1]$ (e.g. previous 7 days or previous 30 days).
  - Aggregates:
    - Total Reach, Views, Engagements, Likes, Comments, Shares.
    - Total Leads captured in CRM, Won Deals, Revenue, Ad Spend, Net ROI.
  - Growth Rate Formula:
    $$\Delta\% = \begin{cases} 0\% & \text{if prior} = 0 \text{ and current} = 0 \\ +100\% & \text{if prior} = 0 \text{ and current} > 0 \\ \frac{\text{current} - \text{prior}}{\text{prior}} \times 100\% & \text{otherwise} \end{cases}$$
  - Trajectory Points: Daily/Weekly intervals for current period vs matched days of prior period.

### 4.2 Frontend UI in `Analytics.tsx`
- Date Range Bar contains:
  - Timeframe selector: `7 ngày qua` | `30 ngày qua` | `90 ngày qua` | `Tháng này`.
  - Checkbox toggle: `[x] So sánh với kỳ trước (F050)`.
- KPI Summary Cards:
  - Each metric card displays:
    - Current Value (e.g. `124,500 Lượt tiếp cận`)
    - Prior Period Comparison pill: `🟩 +18.4% so với kỳ trước` (hoặc `🟥 -5.2%`).
- Charts:
  - Dual line series in Recharts:
    - Solid blue line (`stroke="#3B82F6"`): Kỳ hiện tại (Current Period).
    - Dashed amber/slate line (`stroke="#94A3B8"`, `strokeDasharray="4 4"`): Kỳ trước (Prior Period).
    - Tooltip compares both timestamps side-by-side.

## 5. Verification Plan & Test Matrix Update

### 5.1 F022 Test Cases (`TEST_CASES.md`)
- `TC-F022-01`: Hiển thị tùy chọn "Đăng ngẫu nhiên trong khung" và 4 khung giờ vàng preset.
- `TC-F022-02`: Thiết lập Start Time - End Time tùy chỉnh và kiểm tra sinh thời điểm ngẫu nhiên.
- `TC-F022-03`: Nút "Random lại" xáo trộn thời điểm xuất bản khác vẫn nằm trong khoảng cho phép.
- `TC-F022-04`: Phân bổ thời gian ngẫu nhiên khác nhau cho từng video khi đăng danh sách nhiều video.
- `TC-F022-05`: Bấm xuất bản, bài viết được lưu thành công với trạng thái `SCHEDULED`.

### 5.2 F019 Test Cases (`TEST_CASES.md`)
- `TC-F019-01`: Tải lên tệp Excel `.xlsx` chuẩn và hiển thị đúng bảng Preview dữ liệu.
- `TC-F019-02`: Nhập từ liên kết Google Sheets chia sẻ công khai và trích xuất dữ liệu thành công.
- `TC-F019-03`: Tải file mẫu template `Mau_Import_Bai_Viet_Topify.xlsx`.
- `TC-F019-04`: Kiểm tra cơ chế validation dòng dữ liệu (phát hiện dòng thiếu tiêu đề, dòng thiếu thời gian chuyển thành draft).
- `TC-F019-05`: Xác nhận lưu và tạo bài viết hàng loạt trong cơ sở dữ liệu (`DRAFT` & `SCHEDULED`).

### 5.3 F050 Test Cases (`TEST_CASES.md`)
- `TC-F050-01`: Bật checkbox "So sánh với kỳ trước" trên trang Báo cáo & Phân tích (`/analytics`).
- `TC-F050-02`: Hệ thống tính toán đúng khoảng thời gian kỳ trước tương ứng (7 ngày, 30 ngày, tháng trước).
- `TC-F050-03`: Thẻ chỉ số hiển thị huy hiệu % tăng trưởng xanh `🟩 +%` hoặc giảm đỏ `🟥 -%`.
- `TC-F050-04`: Biểu đồ trực quan hóa hiển thị 2 đường (nét liền = kỳ này, nét đứt = kỳ trước).
